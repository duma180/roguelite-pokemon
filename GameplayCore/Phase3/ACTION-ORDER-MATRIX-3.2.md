# Phase 3.2 action-order conformance matrix

“Runtime-grounded” refers to code-path comparison in the pinned pokeheartgold revision, not a full original-ROM cartridge trace. The test suite verifies the bounded scenarios below.

| Case | Expected Phase 3.2 behavior | Test/evidence | HGSS source basis | Status / limits |
|---|---|---|---|---|
| Different move priority | Higher priority resolves first, even when slower | `MovePriorityPrecedesSpeedAndRecordedOrderIsExecuted` | `battle_controller_player.c:BattleControllerPlayer_CalcExecutionOrder`; `overlay_12_0224E4FC.c:CheckSortSpeed` | **Pass, bounded**; priority modifiers/items and all move-specific ordering remain open. |
| Voluntary switch versus move | Switch action precedes a selected move, including a +5 priority move | `VoluntarySwitchPrecedesMovePriorityEvenWhenSlower` | `CalcExecutionOrder` groups Pokémon actions before Fight actions | **Pass** for single battles. |
| Equal speed | Seeded tie draw is recorded; speed-sorted residual order is sampled separately from action priority order | `ResidualSpeedTieIsResolvedOnceBeforeResidualEffectsAndReplayIsStable` | `SortMonsBySpeed` builds `turnOrder`; `CalcExecutionOrder` builds `executionOrder` | **Pass, structural**; cartridge RNG equivalence for multi-comparison sorting is not established. |
| Speed stages / paralysis | Effective speed uses stages and Gen IV paralysis quartering | Existing action-order tests and `CheckSortSpeed` source | `CheckSortSpeed` | **Partial**; exact integer stat-stage and speed modifiers need broader fixtures. |
| Quick Feet | Gen IV status boost applies and suppresses paralysis quartering | `QuickFeetUsesGenFourStatusSpeedModifierInsteadOfParalysisPenalty` | `CheckSortSpeed` Quick Feet branch | **Pass** for supported single ability. |
| Rain/Sun speed abilities | Swift Swim / Chlorophyll apply under weather when not suppressed | Existing weather-speed tests | `CheckSortSpeed` | **Partial**, only listed abilities. |
| Sand Rush | Not enabled in the HGSS ruleset; available only in the explicit cross-generation profile | `SandRushSpeedBoostIsNotSilentlyEnabledByTheHGSSRuleset` | Sand Rush is post-Gen-IV and absent from the HGSS source path | **Pass** for profile isolation; profile is a narrow prototype, not a modern battle ruleset. |
| Pursuit intercepts switch | A selected Pursuit hits the outgoing identity before replacement; a knockout cancels the selected voluntary switch | Existing Phase 3.1 Pursuit tests | `battle_command.c:BtlCmd_TryPursuit` | **Pass, bounded**; exact priority/PP/damage interactions need ROM traces. |
| Actor is knocked out before queued action | Fainted starting actor does not act even when a reserve keeps the battle alive | `FaintedStartingActorCannotExecuteItsQueuedMoveWhenReserveKeepsBattleAlive` | `CheckSortSpeed` places fainted actors after living actors; controller faint handling | **Pass** for single-target action. |
| Protect | HGSS protection remains selected by the HGSS ruleset, blocks a later opponent action, and chain attempt is recorded | Existing `ProtectPpAndEnvironmentTests` | Protect effect scripts and move priority data | **Partial**; contact effects, Feint, spread attacks, consecutive-chain cartridge probabilities and item interactions are incomplete. |

| Forced switch and replacement | One living reserve is selected deterministically for a supported force-switch move; entrants do not inherit the outgoing queued action | Existing `RoarForcesASeededReplacementAndTheIncomingPokemonDoesNotInheritAnAction` | Force-switch move effect code and `TryReplaceFaintedMon` | **Provisional**; the source's trainer/wild selection, failure conditions, and action/entry-ability sequence are not implemented. |

The implementation exposes no trainer/wild encounter-kind distinction yet. `ReplaceFainted` requires an explicit legal living reserve index. It must not be described as the cartridge's automatic reserve-selection policy.
