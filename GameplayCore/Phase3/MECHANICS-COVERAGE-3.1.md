# Phase 3.1 mechanics coverage matrix

The status values below describe tested code behavior. “Source-grounded” means a corresponding behavior/constant is visible in the pinned pokeheartgold checkout; it does not mean every cartridge edge case has been reproduced.

| System | Phase 3.1 status | Evidence / remaining boundary |
|---|---|---|
| Gen IV stats, types, STAB, critical and damage arithmetic | Reused; partial conformance | Uses frozen Phase 1 `HgssRules`. Added a test for critical stage ignoring negative Attack/positive Defense stages and bypassing Reflect. The full move-specific damage modifier order remains open. |
| Move priority, switch priority, speed ties | Partial | Both actions are fixed at turn start; switch priority is ahead of normal moves; actor identity is retained so forced entrants cannot inherit the outgoing actor's action. No full action queue, multi-battle, Quick Claw, Trick Room, Pursuit/Protect-family interactions, or item order. |
| Pursuit | Implemented pilot | HGSS intercepts a selected voluntary switch, uses doubled power against the outgoing individual, and cancels the selected switch on knockout. Pinned source: `battle_command.c:BtlCmd_TryPursuit`. Priority and all controller edge cases need runtime fixtures. |
| Sleep, freeze, poison, toxic, burn, paralysis | Partial | Existing deterministic counters, residuals, type/ability immunities, thaw and wake behavior remain. Cure moves, all status-source immunities, residual interaction order, Rest, Uproar and every switching case are not complete. |
| Confusion, flinch, infatuation, mean-look switch lock | Partial | Snapshot/deep-copy safe. Late flinch is cleared at turn start, consistent with pinned runtime turn initialization; confusion's exact script timing still lacks ROM fixtures. Binding duration/damage and volatile families are absent. |
| Disable / Encore / Taunt / Imprison | Implemented pilot | Move IDs and counters are part of state hashes; turn restrictions are enforced at execution so same-turn status actions interrupt queued actions; switching clears them. Disable 3–6 and Encore 3–7 RNG ranges follow pinned source. The source's Encore blacklist compares move effects of listed move IDs; the pilot blocks those exact IDs only, so the full effect-equivalence exclusion rule and exact decrement timing remain unimplemented. |
| PP and Pressure | Partial | Normal use consumes one PP; an active opposing Pressure consumes one additional PP, saturating at zero. HGSS Pursuit implementation explicitly decrements a second PP for Pressure. PP-Up, Pressure multi-target, Grudge, Spite, Torment, Gravity, Heal Block, Choice lock and complete Struggle availability rules remain open. |
| Switching restrictions / abilities | Partial | Mean Look-style voluntary lock, Arena Trap, Shadow Tag, Magnet Pull and Suction Cups force-switch denial; switching cleanup preserves major status/PP. Escape items, Shed Shell, Ghost/Levitate grounding matrix, Baton Pass, pivot moves, wild escape and trainer AI choice are unsupported. |
| Forced switch | Pilot / not fully conformed | Deterministic random living reserve and entry hazards are implemented; incoming actor does not receive the outgoing actor's queued action. Gen IV runtime identifies `MOVE_EFFECT_FORCE_SWITCH`; exact trainer/wild selection and failure flow have not been confirmed, so random-reserve selection is provisional. |
| Rapid Spin / entry hazards | Partial | Rapid Spin removes a single active hazard category after a damaging hit in HGSS precedence (Spikes, then Toxic Spikes, then Stealth Rock). Pinned source checks binding and Leech Seed first, then those hazards. Bind and Leech Seed state are not represented. No Defog (later-generation), hazard-entry edge matrix, or all airborne/grounded abilities. |
| Weather | Partial | Existing rain/sun/sand/hail, duration, residual and selected ability interactions remain. Weather move duration/order, weather immunities, Sand special-defense timing and all damage rounding need cartridge-level cases. |
| Reflect / Light Screen | Partial | Existing duration, reduction, critical bypass, single-battle profile. Brick Break, screen setter interruption, item extension and exact timing/rounding not complete. |
| Registry and generation compatibility | Versioned allowlist, not full dispatcher | Effect registry v1.1.0 and ability-hook registry v1.1.0 hash the supported pilot set. Unregistered effect/profile combinations throw. This is not catalog coverage or a fully pluggable Gen I–IX handler graph; per-move/per-ability profile mapping remains required. |
| Persistent battle settlement | Not implemented | HP, PP, status and rewards are not committed to Phase 2 persistent save records. |
| Roguelite scaling and purchases | Not implemented | Exact policy is documented separately; no ranks, price, zone or Gym-ceiling code was added. |

## Acceptance interpretation

The targeted Phase 3.1 slice is accepted by its own tests, but broad priority 1–5 are not complete. Phase 3's original 41 tests remain in the 53-case Phase 3 suite. Conformance is currently strongest for Pursuit dispatch, Disable/Encore source ranges, Pressure PP, turn-start flinch clearing, critical-stage/screen interaction and Rapid Spin hazard precedence. Remaining items are prioritized in `PRIORITIZED-EFFECTS-3.1.md`.
